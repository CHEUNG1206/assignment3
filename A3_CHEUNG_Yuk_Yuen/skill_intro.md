# better-writing

## What it is

better-writing rewrites prose for a named reader and genre. The trigger is a draft that should be clearer, or a request to remove generic AI phrasing. The steps are: set the reader and the facts that must stay, audit the draft, then rewrite. The quality bar is that facts, numbers, and quoted wording stay as they were.

## How to use it

Install path: `.agents/skills/better-writing/SKILL.md`, also linked at `.cursor/skills/better-writing`.

I invoked it on the influence paragraph after policy-funding-card had filled the table. The input was `A3_CHEUNG_Yuk_Yuen/outputs/influence_before.md`. The output is `influence_after.md`. The instruction was to keep every amount, date, and label, and to rewrite only the explanation.

## Work application

In this trainee role I turn public technical or policy pages into a note someone else can check. better-writing is the last pass on the explanation. The funding table stays with the extraction skill. The manual step it replaces is deleting filler from that explanation before I hand the note on.
